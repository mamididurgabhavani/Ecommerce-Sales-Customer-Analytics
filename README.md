# E-Commerce Sales & Customer Analytics

## Overview

An end-to-end data analytics project analyzing e-commerce sales,
customer behavior, product performance, regional sales and returns.

## Objectives

- Analyze sales performance
- Identify top-performing categories and products
- Analyze regional revenue
- Understand customer behavior
- Analyze order returns
- Track monthly revenue
- Evaluate profitability

## Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- SQL
- Excel
- Power BI
- Google Colab

## Project Workflow

Raw Data
↓
Data Cleaning
↓
Exploratory Data Analysis
↓
Feature Engineering
↓
SQL Analysis
↓
Power BI Dashboard
↓
Business Insights

## Key Analysis

- Total Revenue
- Total Orders
- Total Customers
- Average Order Value
- Monthly Revenue Trend
- Sales by Category
- Sales by Region
- Top 10 Products
- Order Return Analysis
- Average Profit Margin

The project includes an interactive Power BI dashboard
